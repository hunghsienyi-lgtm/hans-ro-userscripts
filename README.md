**2026-11-16 起，選關與戰利品已整合為同一支腳本。** 請在 Tampermonkey 將戰利品更新到 v0.7.1；原『文字重進』已更新改為 v2.1.0 的獨立巡走／磁鐵腳本，不再負責重進，自動重進改由右下角戰利品面板內的「重進」開關與關卡選單控制（不再顯示右上角固定視窗）。其餘巫師選技及森林採集維持獨立。安裝前先停用重複用途舊版腳本。後續更新時保留檔名與網址，增加腳本 `@version`，上傳覆寫到 `main`，Tampermonkey 依設定定期檢查 `@updateURL` 並取得 `@downloadURL`。更新頻率依瀏覽器與 Tampermonkey 設定而異；如需即時更新，可在 Tampermonkey 手動檢查更新。

## 安全與已知問題

- 本公開儲存庫**不得**放置 Discord Webhook、密碼、Token、遊戲帳號或 Cookies。
- 戰利品 v0.5.2 **不含私人 Webhook**。安裝後在腳本介面點選「設定 DC Webhook」，資料存於 Tampermonkey 本機設定。
- 整合版會統計結算的「獲得的掉落／卡片」圖示數與可讀名稱；**若遊戲只渲染圖片卻沒有文字／屬性，仍無法可靠確認金裝、TIER 或還原被自動販售的裝備**。結算若無法辨識，等待最多 15.5 秒後留下警告並放行，避免掛機永久卡住。
- 整合版通過 JavaScript 語法檢查與基於 HANS 截圖數據的模擬測試，仍需在當前 HANS 網站實際測試。
- 這裡只提供腳本發布與版本更新，不會自行變更遊戲設定。

## 後續發布原則

版本上升時只更新對應的 `.user.js` 檔案；**不要只提交 ZIP**。提交前檢查腳本中沒有私人資料、四支腳本之間不會重複操控相同功能，並保留固定 `@updateURL` / `@downloadURL`。

## 整合版操作

1. 篡改猴檢查更新，確認「戰利品」v0.7.1 與「開局巡走／磁鐵」v2.1.0 已更新。
2. 重新整理 HANS，點開**右下角**「📦 HANS 選關＋戰利品」，就在同一面板內挑選任一已掃描且已解鎖的遠征關卡（包含原有斐揚、獸人村及向下捲動才能看到的關卡）、啟用「重進」及查看戰利品；不再占用右上角小地圖的位置。
3. 選關畫面會記下六項難度與獎勵倍率，不改動難度滑桿；結算時先記錄縮圖與戰績、封存本場，再按「返回角色」。
4. 右下「場次 CSV」可匯出每局強度、可見縮圖數與有名稱的掉寶紀錄。Discord 發送在本機佇列排隊，不會因網路超時阻塞選關。


### v0.7.1 選關清單掃描

- 打開 HANS 的遠征／選關畫面後，右下角整合面板會自動讀取左側關卡卡片，並從列表頂端一路捲到最下面；讀取到的名稱、Lv 區間與解鎖狀態存在本機。
- 只顯示實際掃描過的關卡；未解鎖關卡在選單中標示並停用。不會憑空假設遊戲有哪些地圖。
- 選定後依照右側預覽與關卡卡片確認，找不到時向下尋找，仍無法確認則停止，避免按錯關卡。
- 本功能保留原有 5.2 秒以上結算封存、最多 15.5 秒等待、難度紀錄、Discord 與右下角介面；尚待 HANS 網頁實測不同捲動清單的 DOM。

**v0.7.1 補強：** 掃描從左側遠征清單頂端（最低等級關卡）開始，等待列表渲染後才一路往下掃；選單按顯示的 Lv 起始等級排序，因此以前的關卡不會被插在尾端。若無法定位捲動清單會顯示診斷，不宣稱完整掃描。實際 HANS 網頁仍需核對。

## v0.7.1：3 分鐘刷樹精卡／短場模式

- 在右下角「📦 HANS 選關＋戰利品」面板選好關卡並開啟「重進」，再點「3分鐘刷卡：開」。**預設關閉**；不影響一般完整通關。
- 遊戲 HUD 正計時到 **3:00** 後，等待所選緩衝秒數（預設 +20 秒，可選 0、10、20、30、45、60 秒），然後送出 ESC，辨識「暫停 → 回到主選單」，再辨識「未完成的一局 → 捨棄」，最後自動重進同一張地圖。
- 注意 HANS 的首位小王可能在 **3:00 才出現**；使用 0 秒可能剛出小王就離場，故預設 +20 秒，不代表保證擊殺／掉卡。時間只看遊戲 HUD，選卡時的暫停不計入。
- 結束前會封存此局已辨識的掉落資料，標記為「主動捨棄，沒有正常結算」。**是否保留捨棄前取得的卡片目前沒有 HANS 官方實證**，請先手動測一場確認物品仍在背包，避免白刷。
- 若發生 ESC 沒反應、找不到「回到主選單」或「捨棄」，腳本會停止自動重進，不會盲點別的按鈕；網頁重新載入時，開關與短場操作狀態可在同一瀏覽器分頁中恢復。
- 其他選技與磁鐵採集腳本未修改。本模式僅在啟用整合腳本的自動重進時執行。

## 新增：v2.1.0 開局巡走／磁鐵／Lv120 免翻牌

這支程式沿用原「文字重進」的檔案與固定更新網址 `HANS_Payon_Auto_Reenter.user.js`，僅提供遊戲內**移動與翻牌停止**。關卡選擇、結算、捨棄重進由右下角 `HANS_Loot_Journal.user.js` v0.7.1 負責，不在此重複操作。

- 遊戲 **00:00–00:59**：在出生點附近按 WASD 短距離巡走，利用遊戲本身的自動攻擊升級，沿路拾取經驗。
- **1:00**：回到偵測到的出生位置，定點攻擊直到 2:00。
- **2:00、3:00、6:00、8:00、10:00、12:00、14:00**：開啟最多 35 秒的磁鐵搜尋，接近後圖示持續消失才暫判拾取；每輪找到或逾時皆返回出生點。錯過的時窗不會堆積補跑。
- **6:00 磁鐵流程完成且已返點**，之後若升級視窗出現 **Lv120 或以上**，點擊「之後不再翻牌」一次。若不到 Lv120，仍讓原有巫師選技腳本運作；不在 6:00 強行跳掉升級。
- 點擊左側「HANS 巡走」按鈕或按 **Shift+6** 啟動；狀態記在當前瀏覽器分頁，重進時維持啟用。首次須啟用。
- 若右下角「3分鐘刷卡」仍開啟，新巡走腳本會暫停移動並要求先關閉，避免 3:00 捨棄打斷 6:00 磁鐵。
- 如舊森林磁鐵採集 v1.9.2 仍在運作，本腳本會在辨識其啟用狀態時嘗試關閉，以防兩支程式同時輸入方向鍵。
- 正常的巫師選技 v1.20、選關＋戰利品 v0.7.1 仍維持原樣。這次腳本已通過語法檢查與模擬時間軸測試，但仍需在當前 HANS 網站測試實際座標、拾取與免翻牌按鈕。


**v2.1.0 Boss 補充：** 偵測到 14:00 之後的 Boss 階段時，即使遊戲 HUD 改成 2:00 倒數，也會把時間換回本場已經過的分鐘；除 14:00 定時採集之外，**Boss 戰期間會持續監看小地圖的磁鐵**，只要有可追蹤的磁鐵就再次尋找、拾取並返點。沒有磁鐵時不在 Boss 戰亂走，回到據點持續自動攻擊。短場 3 分鐘捨棄模式必須關閉。此功能仍需要 HANS 實際戰鬥測試。
